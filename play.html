🎮 Guide des fonctionnalités de l'émulateur

💾 Sauvegardes rapide & fichier

  • 💾 Sauvegarder l'état (State) : Prend une capture instantanée de ton jeu.
  • 📂 Charger l'état : Reprend exactement là où la disquette a été cliquée.
  • 📥 Exporter la sauvegarde (.srm) : Télécharge le fichier de sauvegarde interne du jeu sur ton PC.
  • 📤 Importer la sauvegarde (.srm) : Charge un fichier `.srm` depuis ton PC pour reprendre une partie.

⚙️ Contrôles & Options

  • 🔄 Redémarrer : Relance la console à zéro.
  • ⏸️ / ▶️ Pause / Reprendre : Fige ou relance la partie.
  • 🎮 Configuration : Mappe les touches du clavier ou de ta manette.
  • 😊 Cheats : Permet d'ajouter des codes de triche.
  • 🛢️ Cache Manager : Gère les données temporaires de la console stockées dans le navigateur.
